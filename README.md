# kneipy-core has moved

**This repository is archived.** kneipy-core now lives in
[akademischerverein/av_intranet](https://github.com/akademischerverein/av_intranet),
under [`lib/kneipy-core`](https://github.com/akademischerverein/av_intranet/tree/master/lib/kneipy-core).
av_intranet was its only user.

Its full history was merged in there
([akademischerverein/av_intranet#79](https://github.com/akademischerverein/av_intranet/pull/79)),
so `git log` and `git blame` on `lib/kneipy-core` show the original commits,
with new hashes. This repository's `master` (up to `11992b7`) is that history.
The other branches here are unmerged work from 2018 and were not carried over.

---

kneipy-core is a small library to do double entry based accounting with money as well as goods. From a technical side it's mainly a collection of fairly complex SQLAlchemy model classes.
